## Локальный запуск

Игра загружает данные через `fetch`, поэтому её нужно открывать через локальный сервер, а не как файл:

```
python -m http.server 8000
```

и открыть [http://localhost:8000](http://localhost:8000).

## Мультиплеер

До 30 игроков в комнате играют одну партию: одинаковые год, инструменты и жизненные события. В учебном шаблоне первый день наступает, когда все закончили вводное обучение (но не позже чем через 5 минут); в продвинутом вводного обучения нет. В конце игры открывается итоговый рейтинг с портфелями участников. Для мультиплеера нужен отдельный сервер — как его запустить, написано в [server/README.md](server/README.md).

## Обновление данных

Цены собираются из выгрузок в `data/raw` (папка не хранится в git). Нужны `pandas` и `openpyxl`:

```
python scripts/build_prices.py --check
python scripts/build_prices.py
```

Первая команда только проверяет данные, вторая ещё и записывает `prices/data.json`. При ошибке в данных файл не меняется. После смены выпуска обновите и `prices/tickers.csv`, а на сервере мультиплеера — и `data.json`.

## Консольные команды

Открой консоль браузера (F12 → Console) на странице игры. Команды работают, когда игра уже начата. В мультиплеере команды, меняющие ход партии, отключены.

### Игра

| Команда | Что делает |
|---|---|
| `game.pause()` | Поставить игру на паузу |
| `game.resume()` | Снять паузу, поставленную `game.pause()` |
| `game.nextDay()` | Сразу перейти к следующему дню (работает и на паузе) |
| `game.finish()` | Мгновенно завершить игру и открыть «Итоги года» по текущему портфелю |
| `game.restart()` | Удалить сохранение и вернуться к выбору режима |
| `game.data()` | Текущее состояние игры (портфель, дата, история, тикеры) |
| `game.prices()` | Источник цен текущего года |
| `game.engine` | Игровой движок |

### Карточки категорий

| Команда | Что делает |
|---|---|
| `setCardState('bonds', 'locked')` | Изменить состояние одной карточки |
| `setCardState('all', 'active')` | Изменить состояние всех карточек |
| `cardStates()` | Показать состояния всех карточек |

Карточки: `savings`, `bonds`, `funds`, `currency`, `stocks`, `gold`.
Состояния: `active` — торговля, `locked` — закрыта (замок), `unlock` — доступна для открытия (кнопка «Открыть»).
